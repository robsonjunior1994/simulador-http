# simulador-http
Estou criando uma aplicação mockada usando o Beeceptor (https://app.beeceptor.com/console/robsonjunior1994-api) para simular as chamadas da API caso o serviço real esteja indisponível. Lembrando que essa solução é temporária, e vocês precisarão seguir as minhas instruções para criar os mocks adequados, pois o Beeceptor é apenas uma ferramenta de prototipagem rápida.

Próximos passos: Assim que eu definir os endpoints e os exemplos de resposta, vocês devem replicar a configuração no Beeceptor para garantir que os mocks estejam alinhados com o que a aplicação espera. Qualquer dúvida sobre a estrutura dos mocks, é só me perguntar.
